# 3주차 — 만들어둔 skill들을 함께 쓰기

> 목표: 개별 skill을 **하나의 아침 동작이나 업무 루틴**으로 묶어본다.

## 함께 하는 것
- 1, 2주차에 만든 skill 점검
- 여러 skill을 한 번에 실행하는 흐름 설계
- 반복 사용을 막는 불편함 제거하기

## 이번 주 순서
1. 지금까지 만든 skill을 점검한다: 계속 쓰는 것 / 안 쓰는 것 구분.
2. 안 쓰게 된 skill이 있다면, 왜인지 보고 **다시 켜고 싶어지는 형태**로 다듬거나 과감히 접는다.
3. 세 번째 skill을 만들거나, 기존 skill들을 하나의 루틴으로 묶는다. (예: 아침에 한 번 실행하면 여러 skill이 이어서 도는 흐름)
4. 사용 기록을 갱신한다.

## 손에 남는 것
- [ ] 아침 한 번으로 실행되는 **스타트 루틴** 또는 고도화된 skill
- [ ] (권장) 여기까지 skill **3개**가 모이면 최종 결과물 요건에 가까워집니다

## 멤버 과제
만들어둔 skill을 **고도화한 경험**을 채널에 공유합니다.

## 스터디장 사례글
- 만들어둔 skill들을 한 번에 실행하기

## 이번 주 포인트
- 새 걸 더 만드는 것보다, **실제로 계속 쓰게 만드는 것**이 목표입니다.
- "다시 켜고 싶어지는 이유"가 무엇인지 한 줄로 적어보세요.
