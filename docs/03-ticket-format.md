# 03 · 티켓 양식 — 파일 하나 = 티켓 하나

## 형태

`001-무엇.md` 처럼 번호 붙인 마크다운 한 장이 티켓 하나. (칸반 폴더·단일 TODO 목록 대신 이걸 골랐다.)

## frontmatter

```yaml
---
id: 000
title: <한 줄로 뭘 할지>
type: skill        # skill | mission | fix | agent
status: todo       # todo | doing | done
created: 2026-07-03
---
```

- `type` 에 `agent` 를 추가로 씀 (서브에이전트 티켓용).
- 상태가 바뀌면 `status:` 만 고친다.

## 본문 뼈대

1. 뭘 하려는가 (한 줄)
2. 왜 / 언제 쓰는 일인가
3. 할 것 (체크리스트)
4. 막힌 점 / 메모

## 크기 규칙

**"15분 안에 끝낼 수 있는 범위"** 가 티켓 하나의 크기. 크면 쪼갠다.
스터디 원칙(작게 시작)과 같은 결.
