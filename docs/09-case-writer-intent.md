## 참가자가 정리한 의도

"의도만 잘 전달하고, **무엇을 배웠고 · 어떤 시행착오 · 결과 · 다음에 뭐 할지** 내용만 잘 담기면 된다."

## 확정한 뼈대 (4흐름, 느슨한 가이드)

1. 무엇을 하려 했나 / 배웠나 — 의도
2. 어떤 시행착오 — 막힌 점, 헛발질
3. 결과가 어떠했나 — 전·후 차이
4. 다음에 뭘 할까 — 이어질 것

고정 폼이 아니라 상황 따라 늘였다 줄였다 OK.
