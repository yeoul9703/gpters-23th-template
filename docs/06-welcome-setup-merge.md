# 06 · 결정 — welcome 이 setup 을 흡수

## 상황

- `g23-setup` (있음): OS 확인·k-skill 준비·CLAUDE.md 개인화 = **초기 설정**
- `g23-welcome` (신규): 1주차 온보딩 **실습**

둘 다 "처음"에 쓰는 거라 겹쳤다.

## 결정

`g23-welcome` 이 setup 기능을 **흡수**한다. 한 흐름으로:

```
① 셋업 점검 → ② CLAUDE.md 개인화 → ③ 1주차 실습 1개 → ④ missions 안내
```

`g23-setup` 은 병합 후 **폐기(deprecate)**.

## 남은 결정

setup 을 완전 삭제할지, "welcome 으로 가세요" **얇은 리다이렉트**만 남길지 미정.
기존 "초기 설정" 트리거로 들어올 사람을 고려해야 함. → `_discuss.md`

## 관련

[07 missions 분리](07-missions-separation.md) 와 짝. welcome 은 missions 를 **부르기만** 한다(병합 아님).
