# 07 · 결정 — missions 는 따로 둔다

## 질문

"g23-missions 를 welcome 에 합칠까?"

## 결정: 분리 유지

이유:

1. **생명주기가 다름.** welcome 은 *처음 한 번*(1주차), missions 는 *매주 반복*("이번 주 뭐 해").
   합치면 2~4주차엔 welcome 을 다시 켤 일이 없어 트리거가 어색해진다.
2. **트리거가 깔끔.** "이번 주 미션"·"몇 주차" 는 missions 로 계속 살아있는 게 명확.
3. **연결은 핸드오프로.** welcome 이 1주차에서 missions 를 *안내/호출* 하면 된다. 병합 아님.

## 그림

```
g23-welcome (첫날: 셋업+온보딩) ──안내──▶ g23-missions (매주: 이번 주 할 일)
   └ g23-setup 흡수
```

- "지금 몇 주차인지" 판단 방식 정하기 (날짜? 물어보기?)
