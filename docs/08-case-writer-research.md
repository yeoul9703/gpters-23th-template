# 08 · case-writer 를 위한 조사

사례글 스킬(003)을 잘 만들려고 참고 스킬 두 개를 읽었다.

## k-skill / `korean-humanizer` — 가볍고 딱 맞음

AI 티 나는 한국어 글을 다듬는 스킬. SKILL.md 한 장이라 우리 "작게 시작" 과 맞다. 훔쳐올 것:

- **피할 표현 목록** (구체적):
  - 번역투: `~을 통해`, `~에 의해`, `~의 경우`, 이중피동(`되어지다`), `~을 가지다`
  - 상투구: `결론적으로`, `시사하는 바가 크다`, `이것은 ~인 것이다`
  - 과장: `다채로운`, `진정한`, `궁극적으로`, `혁신적인`, `아우르다`, `담아내다`
  - 구조: 연결어미 뒤 쉼표, 제목 이모지, em-dash, 접속사 남발(`또한/따라서` 5회+)
- 제거 강도 S1/S2/S3, 4원칙(의미 불변·근거 기반·장르 보존·과교정 금지), A~D 자기채점

## kimsh-1/`gn-voice` — 무겁지만 아이디어가 좋음

특정 사람 문체를 복제. 986개 글 코퍼스 + Python + 3에이전트(Runner/Gate/Reviewer).

- 좋은 아이디어: 금지어 별도 파일, 문체 지문, 등급 게이트
- 우리 스터디엔 **과함** — 기계장치는 안 가져온다.
