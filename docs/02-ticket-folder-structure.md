# 02 · ticket 폴더 구조

## 왜 만들었나

기존 레포엔 이미 `missions/`(주차 미션), `examples/`(기록 양식), `.claude/skills/`(스킬)가 있었다.
여기에 겹치지 않게, **"지금 내가 손대야 할 작업 단위"** 를 하나씩 쌓을 곳이 필요했다.

## 정한 구조

```
ticket/
  README.md          쓰는 법 + 티켓 목록 + 관계 지도
  _template.md       티켓 한 장 양식
  001-example.md     예시 티켓 (감 잡으면 삭제)
  002~008-*.md       실제 티켓들
  clips/             지피터스 사례 클리핑 (04 문서 참고)
    README.md
    _template.md
```

## 두 갈래로 나눈 이유

- **티켓** = 내가 **할 일** (만들 스킬, 미션 to-do, 막힌 점)
- **클리핑** = 나중에 볼 **자료** (지피터스 베스트/ax 사례)

성격이 달라서 한 폴더 안에서 `clips/` 로만 살짝 분리. 헷갈리면 티켓으로.

## 나중에 추가된 것

여러 티켓에 걸친 **결정할 것들**은 `ticket/_discuss.md` 에 모으기로 함
(정해지면 각 티켓에 반영). → README 에 안내 추가됨.
