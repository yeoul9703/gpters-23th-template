## 왜 클립했나 (한 줄)

대량 자료(102개 영상)를 "요약"이 아니라 "적용/보류/회피 기준"으로 정리하는 방식 — 스터디 4주차 사례글 구조의 좋은 선례.

## 핵심 요약

- GPTers 22기 영상 102개를 정리한 결과, AI 활용의 핵심은 특정 도구가 아니라 "반복되는 일을 구조로 남기는 운영체계"였다.
- 4단계 정리 구조: 요약 → 개별 분석 노트 → 주차별 정리본 → 전체 INDEX. 각 노트마다 "지금 적용 / 보류 / 하지 말 것 / 지금 할 일" 4항목 기록.
- 주차별 관심사 진화 패턴 발견: 1~2주 도구 지도 → 3주 검증·승인 → 4주 실제 산출물 → 5주 시스템 운영.

## 원문 발췌

- "GPTers 22기 영상 102개를 정리하며 발견한 것은 좋은 도구 목록이 아니라 AI를 운영체계처럼 다루는 구조였습니다."
- "많이 보는 것보다, 다시 쓸 수 있게 정리하는 것이 더 중요하다."

## 내 업무에 어떻게 쓸까

클립 정리 자체에 이 프레임 적용 — 각 클립의 "내 업무에 어떻게 쓸까"를 적용/보류/회피로 더 세분화할지 검토.

## 글쓰기에서 훔칠 점

- 첫 문장에서 결론을 던짐: "발견한 것은 도구 목록이 아니라 ~구조였습니다" — 반전형 요약 도입.
- 102개, 5주차, 25개 같은 정확한 숫자가 글 전체의 신뢰를 지탱.
- Before/After 표로 정리 방식의 변화를 가시화 — 과정담을 산출물처럼 보여줌.
