## 왜 클립했나 (한 줄)

주제 입력→발행까지 end-to-end 9분 파이프라인의 단계별 소요 시간을 공개한 드문 사례 — 자동화 skill의 성과 측정 기준으로 좋음.

## 핵심 요약

- 1인 사업자가 주제 입력 → Claude로 콘텐츠 생성 → 이미지 8장 병렬 생성 → PIL 텍스트 합성 → Instagram Graph API 발행까지 전 과정을 자동화.
- e2e 약 9분(LLM 281초 + 이미지 187초 + 합성·발행 80초)에 카드뉴스 8슬라이드 완성.
- hook 5종 로테이션(비판/클리프행어/통계/의문문/페르소나)으로 도입부 다양화, 이미지가 어두워지는 문제는 밝은 톤 프롬프트 강제로 해결.

## 원문 발췌

- "최근 Claude API로 인스타 카드뉴스 8슬라이드 자동 생성 파이프라인을 직접 만들어봤는데, 지피터스 분들 의견이 궁금해서 공유합니다."
- "비슷한 작업 하시는 분 계시면 어떻게 풀고 계신지 공유 부탁드려요."

## 내 업무에 어떻게 쓸까

스터디 홍보 콘텐츠 제작 skill에 "hook 로테이션" 아이디어 차용. 단계별 소요 시간을 기록하는 습관을 사용 전·후 비교 양식에 반영.

## 글쓰기에서 훔칠 점

- "1인 사업하면서 콘텐츠 자동화 시도 중" — 자기 상황 한 줄 소개 후 피드백을 구하는 열린 자세의 도입.
- 281초+187초+80초처럼 단계별 수치를 쪼개 보여주는 정밀함.
- 완성 자랑이 아니라 "피드백 요청" 형식이라 댓글 참여를 부르는 구조.
