## 왜 클립했나 (한 줄)

바이브 코딩의 마지막 구멍인 "검증"을 도구로 메꾼 후기 — 한계(기획자의 통제 감각 부족)까지 솔직하게 적음.

## 핵심 요약

- Claude Code에 개발을 맡기던 저자가 오픈소스 E2E 검증 도구 Autonoma를 도입, 설치·연결도 Claude Code에 지시.
- Autonoma가 코드베이스를 분석해 테스트 156개 자동 생성(정상 42 / 예외 38 / 상태 전환 47), 에이전트 4개가 실행·분류·유지보수 협력.
- 근거 수치 인용: AI가 같이 짠 코드는 심각한 문제가 1.7배 많고 절반 가까이 기본 보안 검사 탈락. 단, 모든 게 터미널 중심이라 비개발자는 통제 감각이 부족.

## 내 업무에 어떻게 쓸까

skill 산출물에 "AI가 스스로 검증했다는 증거"를 남기는 단계를 추가할 때 참고. 비개발자 대상이면 검증 결과를 화면/문서로 번역해주는 부분이 필요.

## 글쓰기에서 훔칠 점

- 제목이 곧 정서적 훅 — "다 됐어요가 제일 무섭다"는 역설로 시작.
- "데모 전날의 식은땀", "진짜 사용자는 제가 안 해본 행동을 하거든요" 같은 장면·구어 해설.
