## 왜 클립했나 (한 줄)

"기억해줘" 없이 자동 학습되는 메모리 아키텍처 — Claude Code의 CLAUDE.md/메모리 운영과 비교할 기준점.

## 핵심 요약

- OpenAI가 ChatGPT 메모리를 'Dreaming' 아키텍처로 개편: 명시적 요청 없이 대화에서 자동으로 맥락을 학습하고 시간 경과에 따라 갱신.
- 수치 개선: 컴퓨팅 자원 약 1/5로 절감(무료 사용자 확대 예정), 회상력 82.8%, 시간 정확성 9.4%→75.1%.
- 진화 단계는 저장된 메모리 → Dreaming V0 → Dreaming V3(공통 기반). 핵심 3기능: 컨텍스트 이어가기 / 선호 반영 / 시간 인식. 메모리 요약 페이지에서 확인·수정·삭제 가능.

## 원문 발췌

- "OpenAI의 표현을 빌리면, '몇 가지 메모를 적어두긴 하지만 적지 않은 건 전부 잊어버리는 사람과 대화하는 것' 같았습니다."
- "정보를 쌓는 기능은 많았지만, 정보를 늙히고 폐기하는 기능은 없었습니다."

## 내 업무에 어떻게 쓸까

참가자에게 "메모리는 자동일수록 통제 UI가 중요하다"는 교훈으로 연결 — CLAUDE.md를 주기적으로 열어 다듬는 습관 안내에 인용.

## 글쓰기에서 훔칠 점

- 개선을 전부 숫자로 말함(82.8%, 9.4%→75.1%) — 화살표 전후 비교가 특히 강력.
- 수중 촬영 장비, 싱가포르 여행 같은 생활 밀착 예시로 추상 개념을 구체화.
- 문제 → 해결 → 실전 활용 → FAQ → 인사이트의 위계적 완결 구조.
