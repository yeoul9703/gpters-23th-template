## 왜 클립했나 (한 줄)

"매번 눈으로 하던 검수"를 같은 기준으로 반복되는 자동 루프로 바꾼, 문서 작업 루프화의 교과서적 사례.

## 핵심 요약

- TIPS 최종보고서 작성 가이드 433개 항목의 수동 검수를 Claude 기반 '검수 루프'로 전환.
- 만드는 역할과 검사하는 역할을 분리하고, 8개 섹션을 6개 AI가 병렬 작성한 뒤 한 검사자가 통합 검증.
- 렌더 게이트로 "파일은 있는데 화면엔 안 보임" 같은 이미지 경로·레이아웃 문제를 사전 적발.

## 내 업무에 어떻게 쓸까

반복 검수가 있는 문서(보고서·제안서)에 레시피(기준)와 상태표를 분리한 검수 skill을 만들어 적용해볼 것. 양식/내용 2트랙 체크리스트 아이디어를 그대로 차용.

## 글쓰기에서 훔칠 점

- 도입 첫 문장에서 Before(눈 검수)→After(자동 루프)를 한 문장으로 요약해버리는 방식.
- 구체 수치(433개 항목, 8개 섹션, 6명 AI)와 Before/After 표로 성과를 증명.
- 실패 장면("뭐야 레이아웃 다 깨지고")을 구어체로 생생하게 재현해 설득력 확보.
