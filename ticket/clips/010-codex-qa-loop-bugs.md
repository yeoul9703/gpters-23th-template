## 왜 클립했나 (한 줄)

"만들긴 했는데 진짜 끝까지 도는 게 맞나?"라는 막연한 불안을 구체적 체크리스트 5개로 바꿔 잡아낸 QA 루프 사례.

## 핵심 요약

- rona.so 챌린지 인증 시스템에서 새 '맞춤형 스킬' 인증 방식 도입 후 기존 데이터 연결이 끊겨 인증 0회가 된 버그를 Claude Code QA 루프(OMC+ralph)로 해결.
- 막연한 QA를 통과 기준 5개로 변환하고, 데이터 경로 2가지 중 새 경로에 누락된 연결을 발견·수정·중복방지까지 AI가 반복 검증.
- 재검증에서 본인/타인 완료 같은 신원 경계 케이스까지 확인, 마지막은 배포 후 사람이 화면에서 직접 확인.

## 원문 발췌

- "인증의 '출발점' 자체가 달라진 거죠. 그러니 마음에 이런 의심이 들었어요. "원래는 잘 됐는데, 서비스 기획을 바꾸면서 그 연결이 끊긴 거 아닐까?""
- "결론부터 말하면 인증은 단 한 번도 카운팅되지 않는 상태였습니다."

## 내 업무에 어떻게 쓸까

기능 변경 후 불안할 때 "사용자 플로우별 통과 기준 목록화 → AI가 발견·수정·재검증 루프 → 최종은 내 눈으로 확인" 순서를 QA skill로 만들 것.

## 글쓰기에서 훔칠 점

- "분명 만들긴 했는데, 진짜 끝까지 잘 돌아가는 게 맞나?" — 독자의 속마음 인용으로 시작하는 도입.
- 신호등·두 길 사이의 다리·알바생 5명 같은 비유로 추상적 데이터 흐름을 시각화.
- 짧은 선언형과 긴 설명형 문장을 교차시키는 리듬감 있는 호흡.
