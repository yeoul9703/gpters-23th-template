## 왜 클립했나 (한 줄)

"에이전트 작업의 단위가 자리에서 일어나도 안 끊긴다"는 워크플로 변화를 짚은 신기능 소개.

## 핵심 요약

- OpenAI가 6/25 정식 출시한 Codex Remote: ChatGPT 모바일 앱으로 집 컴퓨터의 Codex를 원격 제어 — 프로젝트 확인, 지시, 작업 승인까지.
- QR 스캔 페어링(1:1 연결), 클라우드 샌드박스가 아닌 실제 로컬 파일·자격증명·플러그인을 그대로 사용.
- 6/18부터 Noise 프로토콜 기반 종단간 암호화 적용.

## 내 업무에 어떻게 쓸까

Claude Code 쪽 원격/백그라운드 세션 기능과 비교 표 만들 때 반대편 사례로. 스터디에선 "자리 비워도 되는 작업 설계" 논의 재료.

## 글쓰기에서 훔칠 점

- "지하철에서 문득 '지금 어디까지 했지?' 궁금했던 적 있으시죠" — 독자 경험을 그대로 재생하는 도입.
- 기능 나열 대신 "집 맥에서/지하철에서" 시나리오로 쓰임새를 보여주는 방식.
