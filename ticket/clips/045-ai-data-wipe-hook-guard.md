## 왜 클립했나 (한 줄)

모호한 지시 한 마디로 실데이터가 날아간 사고와 PreToolUse 훅 방어까지 — hooks를 배울 때 쓸 최고의 반면교사 사례.

## 핵심 요약

- 상담센터 바우처 웹앱에 실데이터(내담자 200명, 상담 기록 1,000건, 2년치)를 넣은 지 4일 만에 "테스트한 거 되돌려줘" 한 마디로 AI가 '종결' 분류 상태를 일괄 리셋.
- 변경 기록이 없어 자동 복구 불가 → 수기 재분류로 수습.
- 이후 Claude Code PreToolUse 훅(protect-data.py)으로 분류 데이터 일괄 변경을 실행 전 차단, 우회 경로 발견 후 2차 보강 + 차단 로그까지 28개 케이스 검증.

## 원문 발췌

- "코드는 git이 있고 파일은 휴지통이 있는데, DB 안의 '분류'라는 건 제 머릿속에만 있던 정보더라고요."
- "그때 처음 알았어요 — "되돌려줘"는 제 머릿속에선 범위가 분명한데, AI한테는 해석의 여지가 있는 말이라는 걸요."

## 내 업무에 어떻게 쓸까

참가자에게 "실데이터 넣기 전 백업 + 범위 명확한 지시" 원칙을 이 사례로 설명. 훅 기반 가드는 스터디 심화 세션 소재로 아껴두기.

## 글쓰기에서 훔칠 점

- 사고의 한 마디("되돌려줘")를 제목에 그대로 박아 극적 긴장을 만드는 방식.
- "예상 vs 실제" 대비 구조로 사고 과정을 시간순 재현하는 전개.
- "더 무서웠던 건 그다음" 같은 짧은 문장으로 다음 문단을 끌어당기는 호흡.
