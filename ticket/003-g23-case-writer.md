## 뭘 하려는가 (한 줄)

참가자의 거친 경험 메모를, 담백하고 진짜 같은 사례글로 정리해준다. AI 티는 안 나게.

## 왜 / 언제 쓰는 일인가

기존 `.claude/skills/g23-case-post-writer/` 개선 → 이름 `g23-case-writer` 로 정리.
참가자 대부분 Claude **Pro 요금제** → 스킬 자체가 가벼워야 함
(큰 파일 읽기·다에이전트·Python 검증 전부 배제).

트리거: "사례글 써줘", "후기", "경험 정리"

## 담기는 내용 4가지 (사례글 뼈대)

느슨한 가이드로 둔다 (상황 따라 늘였다 줄였다 OK, 고정 폼 아님):
1. 무엇을 하려 했나 / 배웠나 — 의도
2. 어떤 시행착오 — 막힌 점, 헛발질
3. 결과가 어떠했나 — 전·후 차이
4. 다음에 뭘 할까 — 이어질 것

## 작동 방식 (가볍게)

- 메모 받으면 → 위 4흐름으로 엮어 초안 1개
- 쓰는 동안 **AI 상투구 짧은 목록(10개 안쪽)** 만 피함 — 별도 검사 엔진 아님, 쓸 때 지키는 규칙
- 참가자 말투 살림, 억지 격식·과장 금지

## 참고 (영감 받은 곳)

- k-skill / `korean-humanizer` — "피할 표현 목록 + 담백하게" 정신만 차용
  - 피할 예시: `결론적으로`, `~을 통해`, `~에 의해`, `혁신적인`, `다채로운`, 이중피동(`되어지다`),
    제목 이모지, 접속사 남발(`또한/따라서` 반복), em-dash
- `kimsh-1/gn-voice` — 문체 개인화 아이디어는 봤으나 **기계장치(코퍼스/지문/채점/게이트)는 안 씀**
