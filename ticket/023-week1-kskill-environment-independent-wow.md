## 뭘 하려는가 (한 줄)

1주차 실습부터 k-skill을 참고하게 한다면, **참가자 환경(설치·로그인·API 키)과 상관없이 바로 돌아가면서 "와우 포인트"를 주는** k-skill 예시 선정 기준을 마련한다.

## 왜 / 언제 쓰는 일인가

1주차에 k-skill을 반영할지 논의하다가("1주차 순서" — [[016-missions-official-curriculum-alignment]] 연장선), 실제로 넣으려면 준비가 귀찮아지는 지점이 나왔다:
k-skill 사례 다수는 특정 환경(예: 특정 서비스 로그인, API 키, 설치된 도구)에 의존한다. 1주차는 참가자 전원이 **처음** 겪는 순간이라, 어떤 예시를 고르느냐에 따라 "누구는 바로 되고 누구는 설정부터 막힌다"는 격차가 생긴다. 첫 주는 특히 격차 없이 전원이 와우 포인트를 느껴야 한다.

단서: 공식 결과물 예시 3개(`.claude/skills/g23-missions/reference/official-curriculum.md`) 중
1. **AI 윤문 스킬** — 텍스트 입력 → 텍스트 출력만 필요. 외부 API·로그인 불필요 → 환경 무관 후보 1순위로 보인다.
2. k-skill로 사업자등록·등기부등본 자동화 — 정부 사이트·본인 인증 등 의존성이 있어 보임.
3. 쿠팡·네이버 검색 스킬로 장보기 자동화 — 웹 접근(브라우저/검색 도구) 권한이 있어야 함, 참가자마다 도구 설정이 다를 수 있음.

이 차이를 명시적으로 정리해두지 않으면, 1주차에 아무 k-skill 예시나 추천했다가 참가자 절반이 설정 단계에서 막히는 결과가 나올 수 있다.
