## 왜 클립했나 (한 줄)

이커머스 운영자가 매출·주문건수·판매국가·카테고리 리포트를 매일/주간/월간 텔레그램으로 자동 수신하도록 만든 사례. 코드를 전혀 몰라도 "업무 지시를 누적시켜 자동화로 굳혔다"는 흐름이 비개발자 참가자에게 특히 참고가 된다.

## 핵심 요약

- 이커머스 서비스의 매출·주문건수·판매국가·카테고리 리포트를 매일 텔레그램으로 자동 수신하도록 구성.
- 어드민 로그인 쿠키, Redash API 키, Mixpanel API 키를 연결해 데이터 소스를 확보.
- 브리프 형식·발송 시간(전일/주간/월간)·포함 항목(매출, 주문건수, 국가분포, 카테고리분포 등 8개)을 직접 지정해 자동화 스크립트+스케줄로 굳혔고, 코드를 몰라도 "AI에게 붙여주고 물어보며" 진행했다고 밝힘.

## 원문 발췌

> 원문 그대로 옮긴다. 절대 바꿔 쓰지 않는다 (AI가 재요약한 문장 금지 — 문체 레퍼런스로서 무의미해진다).

- "특정 명령어 하나로 된 게 아니라, 송쎄오가 예전에 브리프 형식·시간·로직을 저한테 직접 지시했고, 제가 그걸 자동화해놔서 지금 같은 리포트가 나오는 겁니다."
- "저는 코드 한줄 읽을줄 모르지만 ai에게 코드 붙여주면 몬말인지 다음에 어떻게 하면 되는 지를 물어보면 어떻게든 되기는 되더라구요"
- "우선 아직도 수많은 반복업무들이 있는데 자동화 해놓고 회사의 성장에 도움이 되는것에 에너지를 쓰고 싶습니다."
