## 왜 클립했나 (한 줄)

정형화된 결과보고서(업체정보·상권분석·손익현황 등 4섹션, 표 14개)를 매번 손으로 채우던 반복 업무를 클로드 skill-creator로 스킬화한 사례 — "반복 업무를 skill로 만든다"는 이 스터디의 목표와 가장 맞닿아 있는 실사용 예시다.

## 핵심 요약

- 소상공인시장진흥공단 컨설턴트가 3주간 24개 컨설팅 결과보고서를 제출하며, 업체정보·상권분석·손익현황·기술도입 전후비교·컨설팅 내용까지 매번 채우는 데 지쳐 스킬을 만듦.
- 잘 만든 샘플 `.docx` 보고서를 업로드하고 skill-creator의 질문(출력형식·색상·폰트·도식화 방식)에 답하는 방식으로 진행 — 클로드가 표 14개의 행/열 구성과 색상 코드까지 역분석해 스킬 파일로 저장.
- "반복 작업이 3개 이상 쌓였다면 스킬 만들 타이밍"이라는 꿀팁과, 누락되기 쉬운 항목(진단요약 박스)은 스킬 안에 ⚠️ 경고로 명시해 해결한 시행착오를 공유.

## 원문 발췌

> 원문 그대로 옮긴다. 절대 바꿔 쓰지 않는다 (AI가 재요약한 문장 금지 — 문체 레퍼런스로서 무의미해진다).

- "**가장 큰 발견:** 스킬을 만드는 게 귀찮아서 계속 미뤘는데, 막상 만들고 나니 \"왜 진작 안 만들었지?\"가 됩니다. 반복 작업이 3개 이상 쌓였다면 그게 스킬 만들 타이밍이에요."
- "**꿀팁 1 — 샘플 파일을 잘 고르세요.** 스킬의 품질은 샘플 문서의 완성도에 달려 있어요. 가장 잘 만든 보고서를 기준 파일로 올리면, 클로드가 그 구조를 그대로 스킬에 녹여줍니다."
- "**꿀팁 3 — 누락되기 쉬운 요소는 명시적으로 강조.** 저는 진단요약 박스가 자꾸 빠지는 문제가 있었는데, 스킬 안에 ⚠️ 경고로 명시해두니 이후엔 누락이 없었어요."

## 결과보고서, 클로드 스킬로 쉽게 하기

### 소개

최근 컨설팅을 한꺼번에 많이 하는 시점이 되어서 결과보고서 쓰는 데 매우 힘들었습니다. 예전에도 클로드 스킬을 써서 해봤는데 결과보고서는 마음이 급해서 스킬을 쓰지 않고 했었어요. 그래도 계속 또 같은 작업을 해야 하기에, 이번에 힘듦을 겪고 나서야 스킬을 만들어 보았습니다.

저는 소상공인시장진흥공단의 **스마트상점 기술보급사업** 컨설턴트로 최근 3주 동안 24개의 컨설팅 결과보고서를 제출해야 했고 지금은 다 제출한 상태입니다. 보고서 한 건당 업체 정보, 상권 분석, 손익 현황, 기술 도입 전후 비교, 컨설팅 내용 정리까지 들어가야 해서 작성 시간이 꽤 걸립니다. 이 작업을 클로드 **커스텀 스킬**로 자동화한 경험을 공유합니다.

* * *

### 진행 방법

사용 도구

*   [**Claude.ai**](http://claude.ai/) ([claude.ai](http://claude.ai/) 웹)

*   업로드한 샘플 보고서 파일 (`운동00_컨설팅결과보고서.docx`)

*   클로드 스킬 크리에이터 (`skill-creator`)

* * *

Step 1. 샘플 보고서 업로드 + 스킬 제작 요청

먼저 기존에 잘 만들어진 보고서 파일을 클로드에 첨부하고, 아래처럼 스킬 제작을 요청했습니다.

**사용한 프롬프트:**

```
너의 skill-creator 스킬을 사용해서 함께 스킬을 만들어보자. 
이름은 결과보고서다. 먼저 그 스킬이 무엇을 해야 하는지 나에게 물어봐.

결과보고서 제작 시 적용할 스킬을 만들 거야. 
결과보고서를 만들 때 항상 쓰는 것은 아니고, 
지금 지정하는 스타일의 결과보고서를 만들고 싶을 때만 활용할 거야.
```

클로드가 먼저 스킬의 성격을 파악하기 위해 질문을 3가지 던졌어요.

*   어떤 사업용 보고서인지

*   출력 형식이 무엇인지

*   업로드한 파일이 표준 템플릿인지

* * *

Step 2. 스킬 스펙 답변

질문에 아래처럼 답변해서 스킬의 디자인 시스템과 구조를 정의했습니다.

```
출력은 한글 파일 (.hwp / python-docx 기반 .docx)
A4 사이즈 제작
색상: 화이트 배경 / 검정 본문 / 중요 문구는 파랑 (#1F3864) 활용
폰트: 제목용 '한국기계연구원(KIMM)', 본문용 '에이두지체'
상권 정보, 손익 등 중요 항목은 도식화 박스로 표현
템플릿은 샘플 문서와 똑같이 재현
```

* * *

Step 3. 클로드가 샘플 문서를 분석하고 스킬 자동 생성

클로드는 업로드된 `.docx` 파일을 직접 파싱해서 문서 구조를 역분석했습니다. 표 14개(Table 0~13)의 행/열 구성, 섹션별 역할, 색상 코드까지 모두 추출해서 스킬 파일로 저장했어요.

생성된 스킬에 담긴 내용:

*   디자인 시스템 (색상 3종, 폰트 2종, 크기 체계)

*   문서 4섹션 구조 및 표 설계 명세

*   진단요약 박스(Section 2 첫 번째 표) 누락 방지 경고 포함

*   보고서 작성에 필요한 입력 데이터 필드 전체 목록

*   python-docx 기반 코드 생성 절차

* * *

실제 활용 방법

스킬 저장 후, 새 업체 보고서가 필요할 때는 이렇게 씁니다:

```
gyeolgwa-bogoseo 스킬 적용해서 아래 업체 결과보고서 만들어줘.

업체명: OOO
업종: OOO
컨설팅 내용: OOO
...
```

클로드가 스킬 파일을 불러와 템플릿 구조에 맞게 보고서를 자동 생성해줍니다.

* * *

### 결과와 배운 점

배운 점 & 꿀팁

**가장 큰 발견:** 스킬을 만드는 게 귀찮아서 계속 미뤘는데, 막상 만들고 나니 "왜 진작 안 만들었지?"가 됩니다. 반복 작업이 3개 이상 쌓였다면 그게 스킬 만들 타이밍이에요.

**꿀팁 1 — 샘플 파일을 잘 고르세요.** 스킬의 품질은 샘플 문서의 완성도에 달려 있어요. 가장 잘 만든 보고서를 기준 파일로 올리면, 클로드가 그 구조를 그대로 스킬에 녹여줍니다.

**꿀팁 2 — 스킬 제작 시 질문에 구체적으로 답하세요.** 클로드가 먼저 질문을 던져주니까, 그 질문에 색상 코드·폰트명·출력 형식을 정확하게 넣어줄수록 스킬 정밀도가 올라갑니다.

**꿀팁 3 — 누락되기 쉬운 요소는 명시적으로 강조.** 저는 진단요약 박스가 자꾸 빠지는 문제가 있었는데, 스킬 안에 ⚠️ 경고로 명시해두니 이후엔 누락이 없었어요.

시행착오

처음엔 "한글 파일로 바로 만들어줘"라고만 했는데, 클로드는 `.hwp` 직접 생성이 안 되고 python-docx 기반 `.docx`로 대신 생성한다는 걸 뒤늦게 알았어요. 출력 형식을 처음부터 명확히 합의해두는 게 중요합니다.

앞으로의 계획

현재는 단일 업체 보고서 생성 기준이지만, 앞으로 여러 업체 데이터를 한 번에 넣으면 보고서를 일괄 생성하는 배치 처리 방식으로 확장해볼 계획이에요.
