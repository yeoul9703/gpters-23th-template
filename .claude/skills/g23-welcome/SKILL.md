# g23-welcome — 첫날 온보딩 도우미

처음 온 참가자를 셋업부터 **"첫 성공 경험"** 까지 손잡고 끌어준다.
①⑤⑥은 직접 진행하고, ②~④는 각 단계를 담당하는 skill을 순서대로 불러 진행한다 — 그 세 단계의 실제 지침은 이 파일이 아니라 해당 skill 안에 있다.
**참가자의 설정 파일을 자동으로 고치지 않는다.** 무엇을 왜 하는지 설명하고, 참가자가 직접 하거나 함께 결정하게 한다.

## 진행 순서 (①→⑥)

이미 끝난 항목은 건너뛰고, 필요한 것만 대화형으로 확인한다. 한 번에 한 단계씩, 질문은 짧게.

> 이 폴더가 아직 clone 직후 템플릿 그대로면(참가자 커밋이 없으면) `g23-setup`을 먼저 불러 작업 공간 스캐폴드(로컬 git 재초기화·CLAUDE.md 최소 정체성·환경 점검)부터 마친다. 이미 초기화돼 있으면 건너뛴다.

### ① 환경 확인
- OS를 묻는다 (macOS / Windows). 이후 명령 안내는 OS에 맞춰 분리한다. bash를 전제하지 않는다.
- Claude Code가 실행 중인지 확인한다 (지금 대화가 되고 있으면 OK).
- 참가자의 Claude Code 사용 경험 수준을 가볍게 확인한다.

> OS별 명령을 실제로 안내해야 하거나(Windows 터미널 종류별 차이) 참가자의 skill 아이디어가 Python을 요구하게 되면 `reference/setup-guide.md` 참고 — 평소 안내에는 읽지 않는다.

### ② k-skill 준비
`g23-kskill-intro`를 불러 진행한다 — k-skill 레포 소개, 마켓플레이스 설치, `market-kurly-search` 실제 실행까지.

### ③ 업무 파악 (skill 후보의 씨앗)
`g23-work-discovery`를 불러 진행한다 — 참가자의 직무·반복 업무·해보고 싶은 것을 짧게 묻는다. 답은 ④⑤에서 쓴다.

### ④ CLAUDE.md 개인화 초안 제안
`g23-personalize`를 불러 진행한다 — ③의 답을 바탕으로 CLAUDE.md 개인화 초안을 제안한다.

### ⑤ 미니 실습 — 5분 안에 첫 skill 하나 (첫 성공 경험)
여기서 멈추지 않고 **그 자리에서 skill 하나를 실제로 만들어 켜본다.** 이 단계만으로 완결되게 진행한다.

1. ③에서 나온 반복 작업 중 **가장 작은 것 하나**를 고르게 한다. 핵심은 "내 반복 업무를 실제로 자동화해보는 경험"이지, 특정 시간대나 틀에 맞추는 게 아니다. "이 중에 손이 많이 가는 게 있으면 골라도 되고, 다른 반복 작업이 떠오르면 그걸 써도 됩니다"로 안내한다. 특정 업무나 시간대를 예시로 먼저 던지지 않는다 — 참가자마다 직군이 다르고, 예시를 먼저 보여주면 그게 정답처럼 보여 자유로운 선택을 좁힐 수 있다.
2. 참가자가 고른 업무에 맞춰 `.claude/skills/{skill-이름}/SKILL.md` 파일 하나를 **5줄 수준**으로 함께 만든다 — `name`, 트리거 문구가 들어간 `description`, 짧은 본문 한 줄. 내용은 Claude가 그 자리에서 참가자의 업무에 맞게 새로 쓰되, 어디에 어떤 파일이 생기는지 참가자에게 보여주고 동의를 받는다.
3. 만든 직후 방금 정한 트리거 문장을 말해 **바로 한 번 실행**해 본다. 트리거가 발동하는 것만으로는 부족하다 — 나온 결과를 참가자가 직접 보고 "이거 말이 되네, 쓸만하네"라고 확인하는 순간이 첫 성공이다.
4. 성공을 확인했으면 다음으로 이어간다:
   - "방금 만든 건 연습용이에요. 진짜 업무용 skill 후보는 `g23-thinking-partner`로 고르고, 고른 후보는 `skill-creator`로 제대로 만들어요."
5. 방금 겪은 5분짜리 성공 경험을 짧은 사례 게시글로 남긴다. `g23-case-writer`를 불러 정리를 돕게 한다 — 재료가 이 한 번의 시도뿐이어도 충분하다(4주 치를 기다리지 않는다).
   초안이 나오면 참가자에게 직접 gpters.org에 **`OT 과제 (미니 사례)`** 태그로 발행하게 안내한다. 발행은 참가자 본인 계정으로 참가자가 직접 한다.

### ⑥ missions 핸드오프
- 온보딩이 끝났음을 축하하고, 다음 행동 한 문장을 준다:
  > 이제 **"이번 주 미션 알려줘"** 라고 말하면 `g23-missions`가 1주차부터 안내해요.

## 하지 말 것
- `.claude/settings.json`, hooks, 권한 설정을 자동으로 만들거나 수정하지 않는다.
- 참가자가 요청하지 않은 파일을 대량 생성하지 않는다. (⑤의 SKILL.md 한 장은 예외 — 동의 받고 만든다.)
- OS나 요금제를 넘겨짚지 않는다. 모르면 묻는다.
- 큰 파일을 통째로 읽지 않는다. 참가자 대신 결정하지 않는다 — 선택지를 주고 고르게 한다.
- ②~④의 실제 지침을 이 파일에 다시 적지 않는다 — 해당 skill을 호출한다.
