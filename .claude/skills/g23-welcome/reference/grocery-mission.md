# 첫날 장보기 미션

> `g23-welcome` ②에서만 읽는다. 가격·할인율·상품 목록은 저장하지 않고 실습 때
> `/k-skill:market-kurly-search`로 새로 조회한다.

## 고르는 법

먼저 참가자에게 "뭘 사고 싶으세요?"라고 물어 사고 싶은 상품 이름을 직접 받는다.
감이 안 오면 아래 A~C 예시 중 하나를 골라 그 검색 품목으로 시작한다. 인원·식단·예산은
참가자가 원할 때만 덧붙이는 선택 조건이다. 검색 품목은 3개를 기본으로 하고, 시간이
부족하면 2개로 줄인다.

### A. 1인 아침 장보기

- 인원: 1명
- 식단: 그릭요거트 볼과 간단한 아침
- 검색 품목: 그릭요거트, 그래놀라, 바나나
- 예산: 30,000원 이내
- 선택 조건: 1~2주 안에 먹을 수 있는 양을 우선

### B. 2인 저녁 장보기

- 인원: 2명
- 식단: 닭고기 카레와 샐러드
- 검색 품목: 닭가슴살, 카레, 샐러드 채소
- 예산: 40,000원 이내
- 선택 조건: 조리 시간을 줄일 수 있는 상품을 우선

### C. 4인 주말 아침 장보기

- 인원: 4명
- 식단: 달걀·치즈 샌드위치와 우유
- 검색 품목: 식빵, 달걀, 슬라이스 치즈
- 예산: 50,000원 이내
- 선택 조건: 품절 상품은 대체 상품을 함께 제안

## 라이브 검색 결과에 반드시 남길 것

품목별로 아래 정보를 **루트 `kully-result-{닉네임}.csv` 파일**에 남긴다.
(닉네임은 온보딩 ①-2에서 받은 영문 파일명 닉네임. 예: kim, park-j)

CSV는 아래 6개 열을 이 순서로 쓴다 (welcome ③-5가 이 6개를 읽어 표로 그린다).

1. **상품명**
2. **가격** — 현재 가격 (검색 못 했으면 `검색 못함`)
3. **할인** — 없으면 `할인 없음`
4. **재고** — 있으면 `재고 있음`, 없으면 `품절`
5. **배송료** — 검색 결과에 있을 때만, 없으면 `확인 필요`
6. **URL** — 실제 상품 URL (URL 없는 후보는 표에서 제외)

정보가 검색 결과에 없으면 지어내지 말고 `검색 못함`(또는 `확인 필요`)으로 쓴다.

**콤마 주의**: 값 안에 쉼표(,)가 있으면(예: `8,500원`, `10% (1,200원)`) 그 값을
큰따옴표로 감싼다 — CSV에서 쉼표는 열 구분자라, 안 감싸면 한 값이 두 열로 쪼개진다.
welcome이 표로 그릴 때 따옴표는 떼고 보여준다.

### CSV 포맷 예시

```
상품명,가격,할인,재고,배송료,URL
그릭요거트 500g,"8,500원",할인 없음,재고 있음,무료,https://www.kurly.com/...
그래놀라 시리얼,"12,000원","10% (1,200원)",재고 있음,무료,https://www.kurly.com/...
바나나 1송이,"2,900원",할인 없음,재고 있음,무료,https://www.kurly.com/...
```

위 규칙은 **라이브 검색에 성공했을 때의 최종 결과 계약**이다. 환경 문제로
`reference/setup-guide.md`의 DEMO 경로를 쓸 때만 URL 없는 진단용 표를 잠시 허용한다.
DEMO 표는 최종 장보기 결과나 1주차 완료로 세지 않고, 환경을 복구한 뒤 라이브 검색
결과로 덮어쓴다.

## 장보기 skill 최소 계약

기본 이름은 `my-grocery-planner`로 제안하되 참가자가 바꿀 수 있다.

- 트리거 예시: “장보기 도와줘”, “이번 주 장보기 목록 만들어줘”
- 입력: 사고 싶은 상품 이름 몇 개 (인원·예산·제외 조건은 원할 때만 덧붙이는 선택 사항)
- 처리: 받은 상품 이름을 각각 `market-kurly-search`로 라이브 검색
- 출력: 위 필드를 가진 장보기 표를 루트 **`kully-result-{닉네임}.csv`** 에 저장 (CSV 포맷 위 섹션 참고)
- 금지: 가격·재고·배송 정보를 SKILL.md에 고정하거나 검색하지 않은 값을 추정
