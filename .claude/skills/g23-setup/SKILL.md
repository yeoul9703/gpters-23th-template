# g23-setup — 스터디 초기 설정 도우미

참가자가 스터디를 시작할 준비를 함께 잡는다. **참가자의 설정 파일을 자동으로 고치지 않는다.** 무엇을 왜 하는지 설명하고, 참가자가 직접 하거나 함께 결정하게 한다.

## 진행 순서

이미 끝난 항목은 건너뛰고, 필요한 것만 대화형으로 확인한다.

### 1. 환경 확인
- OS를 묻는다 (macOS / Windows). 이후 명령 안내는 OS에 맞춰 분리한다.
- Claude Code가 실행 중인지 확인한다 (지금 대화가 되고 있으면 OK).
- 참가자의 Claude Code 사용 경험 수준을 가볍게 확인한다.

### 2. k-skill 준비
- [k-skill 레포](https://github.com/NomaDamas/k-skill)를 한 번 둘러봤는지 확인한다.
- k-skill은 Claude Code 플러그인 마켓플레이스로 설치할 수 있다. 설치를 원하면 안내한다:
  ```text
  /plugin marketplace add NomaDamas/k-skill
  ```
  이후 개별 skill은 `/k-skill:<skill-name>` 형태로 부르고, 자격증명이 필요한 skill은 `k-skill-setup`으로 설정한다.
- 이번 스터디는 k-skill을 **그대로 쓰는 게 아니라 참고 사례로 삼아 내 것으로 바꾸는** 게 목적임을 상기시킨다.

### 3. 업무 파악 (skill 후보의 씨앗)
참가자에게 짧게 묻는다. 답을 CLAUDE.md 개인화에 쓴다.
- 어떤 일을 하나요? (직무/업무 성격)
- 매일·매주 반복되는 작은 작업 3가지는?
- 지금 Claude Code로 해보고 싶은 것 하나는?

### 4. CLAUDE.md 개인화 초안 제안
- 루트 `CLAUDE.md`에 참가자의 업무 맥락을 담을 짧은 문단 초안을 **제안만** 한다.
- 예: "나는 ~한 업무를 하고, 반복 작업은 ~이다. skill은 ~에 초점을 둔다."
- 참가자가 원하면 함께 반영하고, 원치 않으면 그대로 둔다.

### 5. 다음 단계 안내
- "이번 주 미션을 알려줘"라고 하면 `g23-missions`가 1주차를 안내한다고 알려준다.

## 하지 말 것
- `.claude/settings.json`, hooks, 권한 설정을 자동으로 만들거나 수정하지 않는다.
- 참가자가 요청하지 않은 파일을 대량 생성하지 않는다.
- OS나 요금제를 넘겨짚지 않는다. 모르면 묻는다.
