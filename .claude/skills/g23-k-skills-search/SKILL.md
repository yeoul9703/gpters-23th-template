# g23-k-skills-search — k-skill 참고 사례 찾기

참가자가 skill을 0부터 복붙하지 않고, 비슷한 사례를 골라 **자기 업무에 맞게 바꾸는 출발점**으로 삼게 한다.

## k-skill이란
잘 만들어진 한국어 자동화 사례 모음. 교통 예매, 부동산, 금융·비즈니스, 쇼핑, 정부·법률, 콘텐츠·글쓰기 등 150개 이상의 skill이 주제별로 있다.
레포: https://github.com/NomaDamas/k-skill

## 찾는 방법 (기본: 웹/레포 링크 기준)

1. 참가자가 만들려는 skill을 한 문장으로 확인한다. (thinking-partner에서 나온 "[언제][입력]하면[출력]" 문장)
2. 그 업무와 **비슷한 성격**의 k-skill 카테고리를 찾는다. 정확히 같은 도메인이 없어도 괜찮다 — 구조와 입력/출력 흐름이 비슷하면 참고감이 된다.
   - 예: "매일 뉴스 요약" → 콘텐츠·검색 계열 사례의 입력→가공→출력 구조를 본다.
   - 레포를 넓게 훑어야 하면 `k-skill-researcher` 서브에이전트에 위임해 후보 3~5개(경로·한줄 요약·이유)만 받아온다. 메인 대화에서 레포를 직접 뒤지지 않는다.
3. 후보 사례 2~3개를 제시하고, 각각에서 **빌릴 점 / 버릴 점**을 정리한다.
   - 빌릴 점: 입력 형식, 출력 형식, 단계 나눔, description 트리거 표현
   - 버릴 점: 특정 서비스 자격증명, 내 업무와 무관한 옵션
4. 참가자가 하나를 고르면, 그 구조를 내 업무 문장에 맞게 바꾼 `SKILL.md` 초안을 함께 만든다.

## 설치해서 직접 써보기 (선택)
그대로 실행해보고 싶으면 플러그인으로 설치할 수 있다.
```text
/plugin marketplace add NomaDamas/k-skill
```
이후 `/k-skill:<skill-name>`로 실행하고, 자격증명이 필요하면 `k-skill-setup`으로 설정한다.
로컬 clone은 필수가 아니다. 필요할 때만 안내한다.

## 원칙
- "k-skill이 다 해준다"가 아니라 "사례를 내 업무로 번역한다"는 태도를 유지한다.
- 사례를 그대로 제출물로 쓰지 않는다. 최소한 입력/출력/사용 흐름 하나는 내 상황에 맞게 바꾼다.
- 없으면 없다고 말한다. 억지로 끼워 맞추지 않는다.
