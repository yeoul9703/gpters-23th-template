# 1주차 — k-skill로 첫 skill 만들기

> 목표: k-skill을 출발점으로 내 업무에 쓰는 **첫 skill**을 만들고, 그 경험을 사례 게시글로 남긴다.

## 이번 주 순서
1. 처음이라면 `g23-setup`으로 작업 공간을 준비하고 k-skill을 설치해 한 번 체험한다. ("스터디 시작 도와줘")
2. `g23-welcome`으로 내 업무를 파악하고, 관련 지피터스 사례 2~3개를 연결한 `gpters-k-skill-report-{닉네임}.html`(4주 로드맵)을 만든다.
3. `g23-case-writer`로 오늘 경험(k-skill 체험 + 4주 계획)을 담은 OT 사례 게시글 초안을 만든다.
4. 로드맵 week-1 아이디어로 내 업무 첫 skill을 실제로 만들어 한 번 써본다. 막히면 `g23-thinking-partner`(후보 고르기)·`skill-creator`(SKILL.md 만들기).
5. 사례 게시글을 완성해 gpters.org에 `OT 과제 (미니 사례)`로 직접 발행한다.

## 손에 남는 것
- [ ] 내 업무에 쓰는 **첫 skill** 1개
- [ ] 내 목표와 관련 사례가 담긴 `gpters-k-skill-report-{닉네임}.html` 1개
- [ ] k-skill 체험과 4주 계획을 담은 OT 사례 게시글 (초안 → 발행)

## 멤버 과제
첫날 OT에서는 k-skill 체험·4주 로드맵·OT 초안까지 완성합니다. 내 업무 첫 skill은 이번 주 안에 만들어 한 번 써봅니다.
skill을 계속 쓸지는 자유입니다 — 계속 쓴다면 실제 사용 기록을 더하고, 접는다면 이유를 한 줄 남겨 4주 회고의 근거로 씁니다.

## 스터디장 사례글
- (예시) AI 윤문 스킬로 자연스러운 글쓰기 해결 — 직군에 상관없이 누구나 있는 고민이라 참고하기 쉽다
