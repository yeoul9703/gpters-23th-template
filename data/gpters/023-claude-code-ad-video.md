## 왜 클립했나 (한 줄)

영상 생성 AI 대신 "코드로 그리는 영상"이라는 역발상 — 통제 가능성을 무기로 삼은 접근.

## 핵심 요약

- Claude Code + 파이썬으로 광고 영상을 프로그래밍 방식으로 제작. 초당 30프레임을 코드로 렌더링해 한글 깨짐 없이 색·타이밍·사운드를 100% 통제.
- ffmpeg로 효과음·배경음 합성까지 마무리, 결과물 2개 버전 공유.
- 같은 코드 파이프라인으로 여러 버전을 빠르게 찍어낼 수 있다는 게 핵심 장점.
