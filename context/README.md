# context — compact 전 세션 맥락 스냅샷

`ticket/*.md`가 **할 일**을 담는다면, 여기는 **왜 그 할 일이 나왔는지의 논의 맥락**을 담는다.
`/compact`로 대화가 압축되기 전, 다음 세션(또는 다음 나)이 처음부터 다시 논의하지 않도록 흐름·근거·미결 질문을 남겨둔다.

## 언제 쓰는 파일인가

- 여러 세션(브랜치)이 같은 저장소를 동시에 편집하고 있어 티켓만으로는 "지금 어디까지 논의됐고 왜 이렇게 됐는지"가 잘 안 보일 때.
- `/compact` 직전, 이번 세션에서 있었던 논쟁·결정·반박·미결 질문을 압축 이후에도 이어갈 수 있게 남길 때.

## 티켓과 다른 점

- 티켓 = 실행 항목(체크리스트, 상태 todo/doing/done).
- context = 서사(무슨 논의가 오갔고, 왜 이 결론/미결 상태에 도달했는지). 실행 체크리스트를 여기 두지 않는다 — 그건 해당 티켓에 있다.

## 파일 만드는 법

- `{주제}-{날짜}.md` 형식으로 하나씩 쌓는다 (예: `week1-mission-2026-07-04.md`).
- 다음 세션이 처음 보고도 이해할 수 있게: 무슨 일이 있었는지 → 아직 안 정해진 것 → 관련 티켓/파일 링크, 순서로 적는다.
- 오래돼서 전부 티켓에 흡수됐으면 지워도 된다 — 여기는 자료 보관소가 아니라 이어달리기용 메모다.
